# Specs (Spec-Driven Development)

Trabalho novo começa aqui. Cada iniciativa vive em `docs/specs/<slug>/` com três arquivos:
`spec.md` (o quê/por quê) → `plan.md` (como) → `tasks.md` (passos executáveis).

Criar com `/create-spec`; revisar com `/spec-review`; executar via tickets
(`tickets/TCK-NNNN-<slug>/`).

**Nenhuma implementação sem spec `approved`.**
