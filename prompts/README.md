# Prompts operacionais

Prompts prontos para colar em ferramentas que **não** carregam automaticamente as skills e
agents do repositório (ChatGPT/GPT via web, Claude via web, assistentes de IDE genéricos).

Nos CLIs com suporte nativo, prefira os comandos: `SLASH_COMMANDS.md`.

| Prompt | Uso |
|---|---|
| [bootstrap-session.md](bootstrap-session.md) | Abrir uma sessão em ferramenta genérica com o contexto mínimo do projeto |
| [assume-agent-role.md](assume-agent-role.md) | Fazer o modelo assumir um dos papéis de `.claude/agents/` |
